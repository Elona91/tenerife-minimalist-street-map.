# Tenerife Minimalist Street Map & Tourism POI Project

This repository showcases a high-quality vector mapping workflow for Tenerife, shifting the focus from terrain geometry to urban structure and transportation networks. The layout utilizes custom SVG point-layer rendering over a minimalist ivory layout.
